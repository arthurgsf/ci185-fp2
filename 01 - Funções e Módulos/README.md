# Conversão de graus e radianos
Relação fundamental: $180\degree = \pi rad$
## Converta um ângulo de graus para radiano
Fórmula: $rad = graus \times \frac{\pi}{180} $

## Converta um ângulo de radiano para graus
Fórmula: $graus = rad \times \frac{180\degree}{\pi}$

# Distância Euclidiana
## Calcule a distância euclidiana entre dois pontos A = (x1, y1) e B = (x2, y2)
Fórmula: $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$
